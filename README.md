AraFert

A simple guitar fretboard tool for exploring musical keys and scales.
everything in this project was Workeout and produced Indiependently.
Top credits : Reddit & Stackoverflow 
Some scripts has been Obfuscated on purpose (to prvent copying logic) 

Features : 

- Interactive fretboard
- Key and scale selection
- Scale playback
- Drone mode

Files

- "index.html" — HTML structure
- "styles.css" — Styling
- "app.js" — Fretboard logic and audio

Obfuscation

- JavaScript: "obfuscator.io" (https://obfuscator.io/)

Usage

Open "https://arpacode.github.io/Arafret/" in a browser and start exploring.
